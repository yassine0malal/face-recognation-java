FICHIERS HAARCASCADE REQUIS
============================

Télécharge les fichiers XML suivants depuis le dépôt officiel OpenCV :
https://github.com/opencv/opencv/tree/4.x/data/haarcascades

Fichiers nécessaires :
1. haarcascade_frontalface_default.xml
2. haarcascade_smile.xml

Place-les dans ce dossier (src/main/resources/haarcascades/)

Liens directs :
- https://raw.githubusercontent.com/opencv/opencv/4.x/data/haarcascades/haarcascade_frontalface_default.xml
- https://raw.githubusercontent.com/opencv/opencv/4.x/data/haarcascades/haarcascade_smile.xml
